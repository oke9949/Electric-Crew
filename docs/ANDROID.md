# Electric Crew Android

Az Electric Crew aktuális telepíthető Android APK-ja a GitHub Releases oldalon érhető el:

- [Electric-Crew-10.0.2.apk](https://github.com/oke9949/Electric-Crew/releases/download/android-v10.0.2/Electric-Crew-10.0.2.apk)
- Csomagazonosító: `hu.electriccrew.app`
- Verzió: `10.0.2`

## Beépített frissítés-ellenőrzés

A 10.0.2 kiadástól az Android alkalmazás induláskor és az appba való visszatéréskor ellenőrzi a legfrissebb stabil GitHub Release-t. Ha magasabb verziójú APK érhető el, az alkalmazás frissítési bannert jelenít meg, ahonnan közvetlenül elindítható az APK letöltése és az Android telepítője.

Az Android biztonsági modellje miatt a telepítés végső jóváhagyását a felhasználónak kell megadnia; az alkalmazás nem végez csendes, felhasználói megerősítés nélküli APK-telepítést.

A 10.0.2 verziót egyszer manuálisan telepíteni kell. Ettől a verziótól kezdve a későbbi kiadások elérhetőségét az alkalmazás automatikusan jelzi.

Minden új kiadás saját verziószámot, APK-fájlnevet és GitHub Release-címkét kap.

Az APK hibakeresési kulccsal aláírt, közvetlenül telepíthető tesztkiadás. A Google Play Áruházhoz külön, tartós kiadási kulccsal aláírt AAB szükséges.
